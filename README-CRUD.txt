GLOBAL GREEN — CRUD домашнее задание

1. Откройте папку PRACCCCC-main в VS Code.
2. Запустите global.html через расширение Live Server.
3. Нажмите «УПРАВЛЕНИЕ ТОВАРАМИ» в меню или откройте admin.html.
4. Используйте поиск, «Добавить товар», «Подробнее», «Изменить», «Удалить».
5. Откройте «МАГАЗИН» — в нём отображаются те же товары.

Начальные товары загружаются из products.json, а изменения сохраняются в localStorage данного браузера. Это учебная клиентская CRUD-система без сервера и без авторизации. Изменения не записываются автоматически в products.json и не синхронизируются между разными устройствами. Кнопка «Скачать JSON» выгружает обновлённые данные; вы можете заменить ими products.json для обновления исходного набора.

Новые файлы: admin.html, admin.css, admin.js, products-store.js.
Изменены: magazin.html, products.js, global.html, voda.html, contacts.html.
